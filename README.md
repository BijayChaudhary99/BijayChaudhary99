## Featured Projects

### TutorPro / SLU PeerTutor
A full-stack peer tutoring platform designed to help university students find verified tutors, book tutoring sessions, manage schedules, and leave reviews.

**Key Features**
- Student, Tutor, and Admin role-based dashboards
- JWT authentication and protected routes
- Verified tutor approval workflow
- Tutor search by course
- Booking and review system
- Secure backend API with Express and MongoDB
- Dockerized frontend and backend
- GitHub Actions CI/CD workflow
- DockerHub image publishing

**My Focus**
- Frontend structure and user interface flow
- Homepage and user experience improvements
- CI/CD workflow setup using GitHub Actions
- Dockerfiles for frontend and backend
- Docker Compose setup for local development
- Deployment preparation and environment consistency

**Tech Used:** React, Vite, Node.js, Express, MongoDB, Mongoose, JWT, Docker, GitHub Actions

### Adaptive Sockets
A congestion-aware load balancing framework for real-time communication systems.

This project focuses on improving real-time application performance by routing client traffic based on live server metrics instead of using static routing strategies.

**Key Ideas**
- Real-time latency and load monitoring
- Congestion-aware server selection
- EMA-based smoothing and trend estimation
- Failure detection and reassignment
- Lightweight software-only architecture

**Tech Used:** Python, AsyncIO, TCP/UDP sockets, WebSocket dashboard, Chart.js

---

### DepthVision Lab
A computer vision project comparing classical stereo 3D reconstruction with deep learning-based monocular depth estimation.

**Key Work**
- Captured stereo image pairs
- Estimated fundamental matrix using feature matching and RANSAC
- Performed image rectification
- Generated disparity maps using SGBM
- Reconstructed 3D point cloud
- Compared classical stereo depth with Depth Anything V2

**Tech Used:** Python, OpenCV, NumPy, Matplotlib, PyTorch, Transformers, Google Colab
